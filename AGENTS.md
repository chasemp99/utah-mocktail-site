# Rules for editing the Utah Mocktail Co. website

Read this whole file before changing anything. It applies to any AI helper (Claude, Grok, ChatGPT, Copilot) and to people.

The live site is https://utahmocktailco.com. Cloudflare publishes whatever is on the `main` branch about a minute after it changes, so a mistake on `main` is public right away.

## How to make a change

1. **Work on a new branch, never on `main`.** Name it after the change, like `update-prices` or `new-winter-menu`.
2. **Edit `build-pages.py`, not the `.html` files.** All 7 pages (`index`, `weddings`, `corporate`, `packages`, `gallery`, `reviews`, `team`) are generated by that script. Any hand edit to an `.html` file gets wiped out by the next build, and the automatic check will fail.
   - Business facts (name, phone, email) are variables at the top of the script.
   - Prices and packages, drinks, reviews (`REVIEWS`), team (`TEAM_MEMBERS`) and gallery items are lists inside the script. Search for the words you want to change.
   - Styling lives in `styles.css`, which you edit directly.
3. **Rebuild:** run `python3 build-pages.py` from the repo root. Commit `build-pages.py` and the changed `.html` files together.
4. **Open a pull request into `main`.** Cloudflare posts a preview link on the pull request. Open it on a phone and a computer before merging.
5. **Change only what was asked.** Don't reword headings, reorder sections or "clean up" code that wasn't part of the request.

## Don't touch (these keep Google search and tracking working)

- The Google Analytics tag (`GA_ID`, `G-688F3T92W2`) and the `generate_lead` event in the form script.
- Canonical links, the `LocalBusiness` schema block, page titles and meta descriptions (unless the change is specifically about them).
- `FORM_URL`. It sends date requests to Jake's email and a Google Sheet.
- `robots.txt`, `wrangler.jsonc`, `.assetsignore`, `.github/`.
- `sitemap.xml`. The only exception is adding a new page: add its clean URL (no `.html`), and add the page to the build list at the bottom of the script.

## Content rules

- **Reviews must be real and word for word**, with the reviewer's first name and where it came from (Google, Instagram). Never write, invent or "improve" a review. Fake reviews break FTC rules and Google's policy.
- Photos must be real Utah Mocktail Co. events or drinks. No stock or AI images of "our work". Resize to about 1600px on the long side and keep each file under about 300 KB. Put them in `images/` and give every image real alt text.
- Write plainly, like Jake talking to a customer. Avoid hype words like elevate, unforgettable, seamless or transform.
- Keep the look in `design.md`: cream, dark brown and gold colors, Cormorant Garamond for headings and Inter for body text.
- Phone (928) 266-8863 and utahmocktailco@gmail.com stay the same unless Jake says otherwise.

## The automatic check

Every pull request runs `scripts/check_site.py`. It fails if:
- the `.html` pages don't match what `build-pages.py` produces (someone hand-edited a page or forgot to rebuild),
- a page is missing the Analytics tag or its canonical link, or
- a page has a `noindex` tag.

If the check fails, fix the cause. Don't delete or skip the check.
